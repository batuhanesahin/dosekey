# Medication selection scope

Reviewed 2026-09-15. The lists record the user's existing dose; no suggested starting dose, escalation, conversion, or equivalence is implemented. This is not an exhaustive country-specific availability catalog.

- Ozempic: injection dose amounts only. https://www.novo-pi.com/ozempic.pdf
- Mounjaro: 2.5, 5, 7.5, 10, 12.5, 15 mg; separate per-dose volumes of 0.5 and 0.6 mL. Whole-pen volume is not used as the administered volume. https://pi.lilly.com/us/mounjaro-uspi.pdf
- Wegovy: injection dose amounts only, including 7.2 mg HD in the referenced US label. https://www.novo-pi.com/wegovy.pdf
- Rybelsus: both formulation strength sets appear as distinct values, with no interchangeability implied. https://www.ema.europa.eu/en/documents/product-information/rybelsus-epar-product-information_en.pdf and https://www.novo-pi.com/rybelsus.pdf
- Saxenda: selectable dose amounts only. https://www.novo-pi.com/saxenda.pdf

Volumes are omitted where the current app does not identify the exact presentation. Existing manually entered dose/volume pairs remain available as explicitly labeled existing-record values; changing medication clears them. New input must be selected from the dropdown. Users see a short instruction to select the value matching their own product. Oral Ozempic/Wegovy are outside this existing app's medication-form scope.
